## 📖 О проекте

**«Удаление мусорных приложений Microsoft Store»** — это легковесная утилита для Windows 10 и Windows 11, созданная в формате HTA (HTML Application). Она позволяет быстро и безопасно избавиться от предустановленного «мусора» (Bing Погода, Новости, Clipchamp, Skype, OfficeHub и т.д.), который Microsoft навязывает пользователям.

В комплекте идёт **визуальный редактор списка** (HTML-страница), с помощью которого можно легко добавлять или удалять приложения из списка на свой вкус, не редактируя код вручную.

## 🎯 Зачем это нужно?

Стандартные средства Windows 10 и 11 не позволяют удалить многие встроенные приложения (кнопка «Удалить» неактивна). Скрипты из интернета часто ломают систему или требуют сложной настройки.

**Наше решение:**

- **Простота:** Запустил `.hta` — выбрал галочками — нажал «Удалить». Всё.
- **Безопасность:** Используются официальные методы PowerShell (`Remove-AppxPackage`) и `winget`. Никаких сторонних библиотек или «ломающих» систему твиков.
- **Гибкость:** Встроенный редактор позволяет составить свой собственный список «мусора».
- **Чистота:** После удаления скрипт автоматически перезапускается и показывает, что действительно было удалено, а что осталось.

## 🚀 Как использовать

### 1. Удаление приложений

1. Скачайте файл `Удаление мусорных приложений Microsoft Store.hta`.
2. Запустите его (потребуются права администратора).
3. Отметьте галочками приложения, которые хотите удалить.
4. Нажмите **«Удалить выбранное»**.
5. Дождитесь завершения процесса в открывшемся окне PowerShell. После этого HTA перезапустится и покажет результат.

> ⚠️ **Важно:** Некоторые системные приложения (например, `Microsoft.MicrosoftOfficeHub`) могут «сопротивляться» удалению. Скрипт использует несколько методов обхода, но в редких случаях Windows может восстановить их при обновлении.

### 2. Редактирование списка

1. Откройте файл `Editor.html` в любом современном браузере (Chrome, Edge).
2. Нажмите **«Обзор...»** и выберите ваш `.hta` файл.
3. Удаляйте приложения крестиком или добавляйте новые, вставляя полный путь к папке (например, `C:\Program Files\WindowsApps\Microsoft.BingWeather_...`).
4. Нажмите **«Сохранить изменения»** — браузер скачает обновлённый `.hta` файл. Замените им старый.

## 🛠️ Технические детали

- **Язык:** VBScript (внутри HTA), PowerShell (для удаления), HTML/CSS/JS (для редактора).
- **Методы удаления:** Комбинация `Remove-AppxPackage` (для текущего пользователя и всех пользователей) и `Remove-AppxProvisionedPackage` (для очистки заготовок).
- **Совместимость:** **Windows 10** и **Windows 11**. Требуются права администратора. Работает на всех редакциях (Home, Pro, Enterprise).
